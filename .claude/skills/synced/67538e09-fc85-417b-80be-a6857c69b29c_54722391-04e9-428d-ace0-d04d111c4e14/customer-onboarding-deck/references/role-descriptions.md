# Master Role Descriptions (Slide 9 — Project Team Roles)

Canonical role → description → touchpoint mappings for the Project Team Roles
table. Use these verbatim when a staffed role matches one below. If a staffed
role isn't in this list, ask the user for a one-line description and touchpoint
cadence, then add it here (append a new row, keep the table sorted roughly by
seniority/touchpoint like the rest) so future runs don't have to ask again.
