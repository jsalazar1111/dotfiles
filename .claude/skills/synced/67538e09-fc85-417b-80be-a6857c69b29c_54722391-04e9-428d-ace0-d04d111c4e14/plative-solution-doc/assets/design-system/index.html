Three principles that hold the system together.

Everything else in this guide flows from these. When in doubt, return here first.

  1. Restraint with crimson. Crimson is an accent, never a flood. Reserve it for the single most important moment on a surface — a CTA, a key figure, a section accent.
  2. Open Sans, all the way through. Semi Bold for titles, Light for subtitles, Regular for body. Never substitute system fonts. Never use Fjalla One.
  3. Landscape as background, not foreground. Low-poly scenery and aurora gradients set mood. Type is always the hero — the imagery makes room for it.
